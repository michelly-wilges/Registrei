# Registrei

Sistema de registro de serviços em campo, desenvolvido para permitir que técnicos documentem atendimentos diretamente no local do cliente.

## Objetivo

Evitar perda de informações causadas pelo registro tardio de serviços, garantindo maior precisão no faturamento.

## Funcionalidades

- Registro de serviços
- Registro por áudio com transcrição
- Anexar peças e atividades
- Revisão administrativa
- Exportação para faturamento
